- Date: 2026-11-17 21:26

## Headline numbers (measured, 300 local repos)

| Metric                                                     | Before v0.4.0                                 | After v0.4.0                                             |

| Repos unsafe (suggest-only forever)                        | 34                                            | **1** (Code-To-CV-Agent, list-form `groups:`, by design) |

Root cause was empirical, not guessed: a per-rule sweep plus a Python
YAML audit of the 34 unsafe repos showed valid GitHub schema this tool
never typed — `ignore` (14), `reviewers` (8), `assignees` (5),
`commit-message.prefix-development` (5), `target-branch` (4),
`auto-merge`, `allow`, `versioning-strategy`, `cooldown`, top-level
`registries`/`enable-beta-ecosystems`, ~90 custom-named groups, unknown
keys inside canonical groups. The v0.1.0 `labels` trap, generalized;
each enumerated-modeling release (v0.2.0, v0.3.0) only fixed the keys
someone noticed.

## a) FULLY DONE

1. **Diagnosis with data** — fleet sweep (300 repos), per-rule JSON
   aggregation, per-repo unsafe-construct classification; conclusion
   documented in ADR 0002.
2. **Verbatim passthrough model** (`pkg/dependabot/config.go`):
   `Unmodeled map[string]yaml.Node` inline maps on Config, Update,
   Schedule, CommitMessage, TypeGroup, PatternGroup, Groups — decoded,
   preserved by Reconcile, re-emitted sorted+deterministically by
   Encode, never generated, invisible to Diff. Enumeration-free: future
   GitHub schema needs no code here to stay safe.
3. **Unsafe narrowed to non-round-trippable shapes only**: list-form
   `groups:` (via new `Groups.NonMapping`), YAML aliases and merge keys
   inside captured unmodeled subtrees. `UnsafeReasons` names each. The
   raw second parse, the `known*` field maps, `auditEntries`, and the
   raw↔typed null-entry fold are deleted (that hazard class is
   structurally gone).
4. **`directories` (glob form) modeled**: `Validate` accepts either
   spelling; `Update.coversDir`/`Config.Find` treat globs as covering
   (never duplicate entries; unparseable pattern = covering, the
   conservative direction); orphan detection (`entryDetected`)
   glob-matches against detection.
5. **`Reconcile` fixes**: carries top-level `Unmodeled`; glob-aware fill
   via `desiredIndexOf`; never grafts canonical groups onto entries with
   custom-named groups.
6. **`dependabot-entry-invalid` downgraded error→warning** (unfixable by
   design must sit below the fail-on threshold — BuildFlow gotcha #156).
7. **Semantic `Equal`** (`semanticConfig`/`semanticNode`): node
   position/style/comment metadata and empty-vs-absent lists no longer
   count — cross-decode comparisons work.
8. **Encode fabrication fixes**: `directory`, `patterns`,
   `update-types` are omitempty — no more invented `directory: ""` or
   `patterns: []` (an empty pattern list could make a group match
   nothing).
9. **Errors**: `DecodeStageInspect` removed (single typed pass),
   `FieldDirectory` wording covers both spellings. erraudit: 0
   violations.
10. **Tests**: `config_test.go` rewritten to the new contract; new
    `passthrough_test.go` (12 tests: safety, verbatim encode, Diff
    silence, alias/merge unsafe, anchor-definition safe, directories
    find/validate/orphan, bad-glob coverage); fuzz invariant upgraded to
    round-trip + Unsafe↔reasons with 4 new seeds; customization,
    configure, and provider tests flipped to convergence contracts with
    list-form suggest-only retained at both layers.
11. **Real-world verification**: repaired COPIES of CV (ignore +
    registries + custom groups) and paperless-ngx (directories, docker,
    ~10 custom groups, cooldown, labels, target-branch) — Python
    subset-checker proved zero dropped constructs and zero lost entries,
    second run byte-stable. InboxClean verified convergent no-op.
12. **Gates all green after last change**: `go test ./... -race`,
    golangci-lint fmt+run (my code clean), erraudit 0, `nix build`,
    `nix flake check --all-systems`, `dprint check`, dogfood `--check`
    exit 0.
13. **Docs**: CHANGELOG 0.4.0 section (stale duplicate Unreleased items
    removed), ADR 0002 written, ADR 0001 status annotated, README
    bullets rewritten, AGENTS.md hard-rules + Config-model sections
    rewritten.

## d) TOTALLY FUCKED UP (all self-caught and fixed; ledger for honesty)

1. **My first Reconcile would have destroyed custom groups on the safe
   path**: the group fill REPLACED `update.Groups` wholesale. Caught
   while writing the test — my test asserted the opposite of what my
   code did. Fixed: fill skips entries with unmodeled groups.
2. **`Equal` was position-sensitive**: `reflect.DeepEqual` over
   `yaml.Node` compares Line/Column/Style — cross-decode comparisons
   failed on metadata noise, plus nil-vs-empty `updates:`. Caught by my
   own new fuzz seeds within minutes of enabling the invariant.
3. **Encode fabricated values** (`directory: ""`, `patterns: []`): the
   empty pattern list is semantically dangerous (group could match
   nothing). My ENTIRE synthetic test suite missed both; they surfaced
   only from diffing paperless-ngx's real repaired config. Lesson
   recorded below.
4. **Edit tool messes**: one multiedit duplicated a function signature
   with an orphaned comment block (caught by re-reading); one edit batch
   rejected because `golangci-lint fmt` reformatted between my read and
   write (redone via script).
5. **`git stash` + auto-commit daemon tangle**: stash/pop sequence
   produced "No stash entries found" and a momentary lost-work scare;
   work was intact (daemon had committed it). Lesson: in daemon repos,
   trust `git status`, don't stash to test baseline claims.
6. **Trusted the stale LSP diagnostics panel too long** — it kept
   re-showing already-fixed findings after `golangci-lint fmt` runs; the
   CLI (CI-pinned binary) was authoritative. Should have restarted the
   LSP at the first contradiction.
7. **Invented a test helper that didn't exist** (`EntryDetectedForTest`)
   — replaced with a Diff-level orphan test, which is actually the
   better shape (findings flow through Diff).

## e) WHAT WE SHOULD IMPROVE (process, from this session)

1. **Verify against real-world fixtures FIRST, not last**: the two worst
   bugs (encode fabrication) were invisible to every synthetic test and
   obvious in one real config diff. Corollary: keep sanitized real
   configs (paperless-ngx shape) as regression fixtures.
2. **Evolve fuzz/property generators in the same commit as the model** —
   otherwise the strongest invariants silently stop covering the new
   surface (this session: fuzz got upgraded, property generators did
   not).
3. **Update ALL fleet docs in one pass** (FEATURES/TODO_LIST alongside
   AGENTS/CHANGELOG) instead of discovering them at report time.
4. **Hand-maintained coverage numbers in AGENTS.md drift** — either drop
   the numbers, generate them, or update them per release ritual.
5. **LSP panel vs pinned CLI lint**: when they disagree after formatter
   runs, restart the LSP immediately; the CLI is the gate.
6. **The sweep script should emit per-rule columns** — I hand-rolled the
   same jq aggregation loop twice this session.
