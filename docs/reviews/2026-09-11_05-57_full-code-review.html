01Contract Gaps (fixed)

Contract

Config.Validate promised but never enforced

pkg/dependabot/config.go:262 · pkg/configure/configure.go

The Validate doc comment promised "Repair never writes a config containing invalid entries", yet no production path called it. An existing entry missing directory decoded leniently, survived Reconcile, and would have been rewritten with an empty directory — a config GitHub rejects.

Fixed Run now gates on existing.Validate(); invalid entries produce a dependabot-entry-invalid finding and the file is left untouched. Covered by TestRunInvalidEntryIsSuggestOnly.
Split brain

dependabot.Equal was dead code; DeepEqual inlined instead

pkg/dependabot/generate.go:122 · pkg/configure/configure.go:202

AGENTS.md documents dependabot.Equal as the no-op mechanism, but nothing used it — configure.go inlined reflect.DeepEqual on the reconcile result. Two expressions for one concept, one of them lying in docs.

Fixed configure.Run now calls dependabot.Equal; the inline DeepEqual and the reflect import are gone.
UX

--enable-security-fixes outcome invisible in text mode

internal/cli/root.go

The outcome string (enabled / skipped-no-token / API error) was only emitted under --json. Text-mode users got zero feedback about a network action they explicitly requested.

Fixed Text mode now prints "security fixes: <outcome>".
Robustness

Unbounded HTTP client for the GitHub API

pkg/configure/github.go

EnableSecurityFixes used http.DefaultClient (no timeout). A stalled GitHub API would hang the CLI forever.

Fixed Dedicated client with a 15s timeout; context still governs cancellation.
Correctness

Empty schedule interval treated as present

pkg/dependabot/generate.go

schedule: {} decoded to a non-nil Schedule with an empty interval: no finding, no fill, and an output GitHub rejects.

Fixed scheduleMissing treats nil-or-empty as missing in both Diff (finding) and Reconcile (weekly fill). Covered by TestRunFillsEmptyScheduleInterval.
Precision

Diff hard-coded .github/dependabot.yml despite --config-path

pkg/dependabot/generate.go:169

Findings always pointed at the canonical path even when --config-path overrode it.

Fixed Diff takes the file path as a parameter; Run passes the configured path.
Honesty

Provider Repair lied about dry-run

pkg/provider/provider.go

The default branch reported "held back by dry-run" even when no dry-run was active (e.g. canonical config with informational orphan findings).

Fixed Dry-run is captured once; the non-dry-run default now says "nothing to write; N informational finding(s) reported".
Coverage

github.go had zero tests; URL hard-coded

pkg/configure/github.go

The API adapter was untestable (hard-coded api.github.com) and untested. pkg/configure coverage sat at 64% — below the 80% target in AGENTS.md.

Fixed API root and client are now overridable via SetGitHubAPIForTest; httptest suite covers enabled/not-found/forbidden/error outcomes plus auth header, method, and path assertions. Coverage 81.4%.
Hygiene

Minor smells: cap shadowing, lying test helper, import order

generate.go · configure.go · config_test.go · provider.go

The CapInfo variable shadowed the builtin cap; bytesEqualLines claimed line-wise comparison but was plain string equality; provider.go imports were unsorted.

Fixed Renamed to capInfo, removed the helper, sorted imports.

03Open / Noted

Open

pkg/provider remains 0% covered

pkg/provider/provider.go

The BuildFlow wiring (the code an external system actually executes) has no in-repo test. Stays in TODO_LIST; needs a toolsdk harness decision first.

Noted

Result.SecurityFixes is a plain string

pkg/configure/configure.go

Outcome values are documented constants but the field is untyped string; a defined SecurityFixesOutcome type would make invalid outcomes unrepresentable. Deliberately not changed now: the JSON wire shape is a contract and churn buys little.

Noted

Duplicate entries pass through Reconcile

pkg/dependabot/generate.go Reconcile

Two entries with the same (ecosystem, directory) are both preserved. GitHub rejects such configs anyway and dropping user entries would violate the safety contract; Validate could report duplicates as a finding if it ever bites.

Noted

Edge cases left alone deliberately

pkg/detect · pkg/configure/github.go

.github/workflows nested subdirectories count as Actions workflows (GitHub ignores nesting — over-detection, harmless); repoSlugFromGit reads .git/config so worktrees and submodules report skipped-no-remote. All documented in code comments; revisit on real-world reports.
